About

I hold a B.Sc. in Cybersecurity from Osun State University and work as a junior penetration tester with confirmed findings across real-world targets through Nigerian cybersecurity and bug bounty circles. My focus areas are web application security, API penetration testing, and vulnerability assessment, and I build my own recon and automation tooling as I go — including the CYRECON framework and a set of smaller Python and Bash utilities that speed up the recon-to-report workflow.

I'm currently deepening my exploitation and vulnerability research skills alongside day-to-day bug bounty work, with the aim of taking on more advanced offensive security engagements.

"My goal is to grow into a world-class offensive security professional, contribute to the bug bounty community, and help secure Africa's digital infrastructure."
