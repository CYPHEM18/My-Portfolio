# Femisola Odejide Francis — Portfolio

Personal portfolio site for Femisola "Cyphem" Odejide Francis, a cybersecurity
student and junior penetration tester based in Osogbo, Nigeria. Covers web &
API penetration testing, vulnerability assessment, recon automation, and bug
bounty work, plus a showcase of tools built along the way (CYRECON,
Jsanalyzer, Combo-GEN, WORDGEN, SORTER_V3, and more).

**Live site:** https://my-portfolio-orcin-two-15.vercel.app/

## Tech

Plain HTML, CSS, and vanilla JavaScript — no framework, no build step, no
dependencies beyond two Google Fonts. The whole site lives in a single
`index.html` file, which keeps it simple to host anywhere that serves static
files.

## Running locally

No install needed. Either:

- Open `index.html` directly in a browser, or
- Serve it locally for a closer-to-production feel:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

Deployed on [Vercel](https://vercel.com) as a static site. Any push to `main`
redeploys automatically once the repo is imported into a Vercel project.
